> 2026 年 7 月 31 日，DeepSeek 在 API 更新日志里宣布 V4-Flash 正式版（DeepSeek-V4-Flash-0731）上线公测。这份更新最反常的地方在于：模型的架构、尺寸、上下文窗口、价格全部没动，只重新做了后训练，Agent 基准却翻了一倍，直接反超自家 V4-Pro 预览版。

## 正式版和预览版的区别：只有后训练

先说清一个容易混淆的事实：这次更新没有新模型，只有新版本。

| 项目 | V4-Flash-0731（正式版） | V4-Flash-Preview（预览版） |
|------|----------------------|--------------------------|
| 总参数 | 2840 亿 | 2840 亿 |
| 单 Token 激活参数 | 130 亿 | 130 亿 |
| 上下文窗口 | 100 万 tokens | 100 万 tokens |
| 结构 | 与 DSpark 版相同，附投机解码模块 | 相同 |
| 变化 | 仅重新后训练 | — |

<small>*数据：DeepSeek 官方 API 更新日志与 Hugging Face 模型卡，2026-07-31。</small>

DeepSeek 官方在更新日志里写得很直白："DeepSeek-V4-Flash-0731 的模型结构、尺寸和 DeepSeek-V4-Flash-Preview 保持一致，仅重新进行了后训练。"

打个比方：基础训练决定模型"学了什么"，后训练决定它"干活的方式"。这次身板没换，变的是做事习惯——怎么拆任务、怎么选工具、怎么发现错误、怎么把一件事从头做到尾。

开发者的第一反应是困惑。21 世纪经济报道描述当时社区的反常感：总参数、激活参数和预览版一模一样，那到底更新了什么？答案是后训练阶段对 Agent 能力的专项强化，这正是这一代模型竞争的真正战场。

## 九项基准：轻量 Flash 反超自家 Pro 预览版

官方公布的数据里，正式版在九项智能体、代码与自动化基准上全面超过 V4-Pro-Preview。更值得看的是与预览版的纵向对比：

| 基准 | V4-Flash-0731（正式版） | V4-Flash（预览版） | V4-Pro（预览版） | GLM-5.2 | Opus-4.8 |
|------|------------------------|-------------------|-----------------|---------|----------|
| Terminal Bench 2.1 | 82.7 | 61.8 | 72.1 | 81.0 | 85.0 |
| DeepSWE | 54.4 | 7.3 | 12.8 | 46.2 | 58.0 |
| NL2Repo | 54.2 | 39.4 | 38.5 | 48.9 | 69.7 |
| Cybergym | 76.7 | 38.7 | 52.7 | — | 83.1 |
| Toolathlon-Verified | 70.3 | 49.7 | 55.9 | 59.9 | 76.2 |
| Agents' Last Exam | 25.2 | 15.8 | 16.5 | 23.8 | 25.7 |
| AutomationBench (Public) | 25.1 | 10.8 | 12.8 | 12.9 | 27.2 |
| DSBench-FullStack | 68.7 | 37.0 | 41.8 | 61.8 | 71.6 |
| DSBench-Hard | 59.6 | 25.8 | 31.1 | 54.5 | 71.7 |

<small>*数据：Hugging Face 模型卡 DeepSeek-V4-Flash-0731 官方评测，2026-07-31。DSBench 两项为 DeepSeek 内部测试集。</small>

两个数字最扎眼。Terminal Bench 2.1 测试模型在真实终端里连续执行任务的能力，从 61.8 涨到 82.7，超过自家 V4-Pro 预览版的 72.1，逼近 Anthropic 旗舰 Opus-4.8 的 85.0。DeepSWE 测的是代码修复 Agent，从 7.3 跳到 54.4，几乎是质的跨越。

激活参数只有 130 亿的轻量模型，在 Agent 任务上反超了 490 亿激活参数的 Pro 预览版。这说明预览版 Pro 的后训练还没做完，也说明 Flash 这条线在后训练上的投入已经到位。DeepSeek 官方原话是"基准测试远超 V4-Pro-Preview"，不是营销话术，表格可以佐证。

## 一个需要留意的评测细节

正式版跑基准的方式值得单独说。官方注明：公开测试集上的 Code Agent 任务，使用 DeepSeek Harness 极简模式（即将发布）作为框架，并用了 max 档推理、topp=0.95、temperature=1.0。

用自家框架测自己，评测环境与真实 API 调用存在差异，第三方复现结果会是更可靠的参考。不过 Harness 是开源生态的常见做法（OpenHands、SWE-agent 都是模型厂商自带的 Agent 框架），分数仍具参考价值，只是别当绝对值。

另一个细节来自第三方评测机构 Artificial Analysis。7 月 31 日更新的智能指数测试中，V4-Flash-0731（最高推理档）得 50 分，可比模型的中位数是 17 分。但它在评测中生成了 2.1 亿个 token，可比模型中位数只有 6200 万——输出量是同行中位数的三倍以上。翻译成人话：它靠大量思考换分数，实际使用中的延迟和 token 消耗会比想象中高，Agent 任务里尤其明显。

## 原生 Responses API：一次接口层面的转向

这次更新在工程层面最实在的，是 DeepSeek 首次原生支持 OpenAI 的 Responses API，并针对性适配了 Codex。

Responses API 是 OpenAI 统一处理模型输出、推理过程和工具调用的接口格式，也是 Codex 客户端与模型交互的主要通道。适配之后，开发者可以在 Codex CLI、ChatGPT 桌面端、VS Code 的 Codex 插件里把 DeepSeek 配置为模型提供方。开发者仍用原来的 `deepseek-v4-flash` 模型名调用，后台自动落到 0731 版本，无需改一行代码。

模型本身也做了配套调整。reasoning_effort 现在支持 low / high / max 三档，控制回答前的思考深度；官方建议 high 和 max 档配合最大 384K tokens 的输出长度。这套参数体系和 Codex、GPT-5.6 的 effort 体系一致，迁移成本很低。

目前 Responses API 只支持 V4-Flash，V4-Pro 预计 8 月初接入。DeepSeek 借 Codex 生态进入编程 Agent 主流工作流，这一步的意图比任何基准分数都明确。

## 价格没变，竞争力没变

正式版没有涨价。延续预览版定价：

| 项目 | 价格（每百万 tokens） |
|------|---------------------|
| 输入（缓存未命中） | ¥1（约 $0.14） |
| 输入（缓存命中） | ¥0.02 |
| 输出 | ¥2（约 $0.28） |

<small>*数据：DeepSeek 官方定价页，正式版发布公告未调整价格，2026-08-01 查询。</small>

Agent 任务和聊天不同，一次任务往往要连续调用几十次模型。成本结构直接决定 Agent 能否日常跑起来。输出两块钱一兆 tokens，配合 1M 上下文窗口，意味着大批量文档处理、长链路自动化这类任务真正摸到了"随便跑"的成本线。

发布时间也耐人寻味。7 月 31 日当天，OpenAI 宣布 GPT-5.6 Luna 输入输出价格降至发布价的约五分之一。两份公告撞在同一天，大模型竞争从拼能力上限转向拼"智价比"的信号已经很明确。

## 正式版只来了一半

必须把边界说清楚，这次发布有几个明确的"没动"。

V4-Pro 正式版没有发布。DeepSeek 6 月底预告 7 月中旬上线的 V4 正式版，最终只兑现了 Flash 一半；Pro 的 API、网页版、App 端全部未更改，官方只说"尽快发布"。对 Pro 用户来说，这份更新目前没有价值。

网页与 App 端也没有更新。正式版目前只走 API，普通用户打开的 chat.deepseek.com 仍是预览版模型。这是开发者向的发布，不是消费级产品的发布。

能力边界上，V4 系列此前的硬限制依然存在：仅支持文本，没有图像、音频、视频输入。在 Claude、GPT-5.6、Gemini 都原生多模态的 2026 年，这个短板没有被这次更新触及。横向位置也没有因这次更新发生质变。

## 适合谁用

基于 7 月 31 日发布当天可验证的信息，我的判断是：

- **文本型 Agent 流水线**：最受益的场景。成本低、1M 上下文、工具调用大幅强化，适合批量处理、代码修复、长链路自动化
- **Codex 生态用户**：想给 Codex 换更便宜的模型提供方，这次是官方支持的入口，配置成本最低
- **已用 V4-Flash 的开发者**：模型名不变、价格不变，后台自动升级，无感受益
- **不适合的场景**：需要多模态输入、追求旗舰级通用知识、或等 V4-Pro 正式版的生产环境

这次更新给我的最大印象不是某个分数，而是 DeepSeek 展示的一种能力：在架构和参数完全不变的前提下，靠后训练把 Agent 能力翻倍。这条路要是走得通，意味着"追参数"不再是唯一竞赛方式，后训练工程会成为大模型竞争的主战场。对用户来说，无论这轮模型竞赛怎么打，成本下降和能力上涨都在往同一个方向走——Agent 的日常化，终于不再受制于账单。
