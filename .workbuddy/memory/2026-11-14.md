## 博客新增「小工具」板块（/tools）

目标：把独立 HTML 单页小工具（首个为番茄钟）集成进博客，方便后续持续新增。

### 落地方案
- 注册表唯一真相源：`site/data/tools.json`（slug/title/description/emoji/tags/addedAt/featured）
- 读取层：`site/lib/tools.ts`（校验 slug、去重、置顶+日期排序、embed 路径、冲突检测）
- 工具本体：`site/public/tools/<slug>/view.html`（不进 React 渲染，静态托管）
- 列表页：`site/app/tools/page.tsx` + `site/components/tools/ToolDirectory.tsx`（客户端组件，卡片/列表双视图，偏好存 localStorage `ysj-tools-view-mode`）
- 详情页：`site/app/tools/[slug]/page.tsx`，整屏 iframe 承载工具，顶部条含「工具列表 / 新窗口打开」
- Header 导航新增「工具」（wrench 图标）；sitemap 纳入 `/tools` 与各工具页
- `site/components/layout/FooterGate.tsx`：`/tools/<slug>` 下隐藏页脚，避免 iframe 外多余滚动
- 一键新增：`just add-tool <html> <slug> <标题> <说明> [emoji] [tags]` → `scripts/add-tool.js`
- 测试：`site/tests/lib/tools.test.ts`（元信息完整、slug 唯一、view.html 存在、index.html 冲突守护）

### 关键坑
- 静态导出下 `/tools/<slug>` 会产出 `dist/tools/<slug>.html`；工具入口若用 `index.html` 会与
  详情页路由争夺同名产物，构建后页面变裸 HTML。**入口文件固定命名 `view.html`**，并有测试守护。

### 环境注意

- `next build` 会覆盖 `site/dist`，导致正在运行的 `next dev` 变 500/404，构建后需重启 dev server。

## 新增小工具：房贷计算器（mortgage）

- 源文件：`~/Personal/实用小工具/mortgage-calculator.html`，博客副本 `site/public/tools/mortgage/view.html`
- 视觉与番茄钟同一套变量（page-bg/surface/border/ink/muted/shadow、24px 圆角卡片、系统深浅色），
  仅主色换成蓝色 `--accent`（light #2f7fe0 / dark #6bb0ff）
- 三种贷款口径：商贷 / 公积金 / 组合贷。实现上把贷款拆成若干「本金 + 年利率」段
  （`loanSegments()`），每段独立按月摊还后相加，逻辑只写一份
- 利率模型：商贷 = LPR + 基点/100（默认 3.5% - 40BP = 3.10%）；
  公积金默认 2.6%（首套 5 年以上）；组合贷两段利率各自独立
- 默认利率依据（2026-11 查证）：5 年期以上 LPR 3.5%、公积金首套 5 年以上 2.6%、5 年以内 2.1%
- 还款方式：等额本息 / 等额本金（`.seg-line` 下划线切换，替代原 pill tabs）
- 组合贷隐藏金额滑块（两段金额各自输入）；明细表按年合并两段本息
- 滑块依赖 DOM 顺序紧跟在当前金额行之后，切换类型时靠 hidden 控制显隐
- 本地记忆 key 升级为 `ysj-mortgage-input-v2`（旧 v1 只有单一利率，不兼容读取）

### 交互补充（同日）
- 金额与年限都改成「输入框 + 滑块 + 快捷 chips」三件套，值可在键盘与拖动间任意切换
- 年限范围放宽到 1–50 年，快捷 chips 共 7 档：10 / 20 / 30 / 35 / 40 / 45 / 50
- 窄屏（≤420px）隐藏中间三档 35/40/45（`#years-chips .chip:nth-child(4~6)`），
  只留 10 / 20 / 30 / 50 四个代表档，避免挤成两行；中间档仍可用滑块
- 金额快捷 chips：50 / 100 / 200 / 300 / 500 万；组合贷模式下与金额滑块一起隐藏
- 滑块上下留白加大（`margin: 8px 0 14px`），解决滑块与相邻输入行过挤的问题
- `paintSlider()` 内联调用 `paintAmountChips()`，保证任何金额变化路径都能同步 chips 高亮

### 构建与 dev 的互斥（重要）
- `next.config` 里 `output: "export"` + `distDir: "dist"`，dev 与 build **共用同一个 dist 目录**
- 跑过 `next build` 后再启 `next dev` 会报 `dist/routes-manifest.json` / `app-paths-manifest.json` ENOENT
- 正确顺序：停 dev → `rm -rf site/dist` → 启 dev；生产构建后要预览，必须重新构建而不是复用 dev
- dev 启动时 Next 会清理 dist，可能被注入的安全删除 shim 拦下（SAFE_DELETE_BULK_CONFIRM_REQUIRED），
  因此本机 dev 统一用 `NODE_OPTIONS="" npm run dev` 启动

## 番茄钟：计时期间屏幕常亮

- 用 Screen Wake Lock API（`navigator.wakeLock.request('screen')`）
- 接入点：`commit()` 里 `wakeLock.sync(status === 'running')`，覆盖开始/暂停/重置/切换轮次全部路径
- `visibilitychange` 回前台重新申请（浏览器切后台会自动释放锁）
- 失败（低电量模式、权限拒绝、Firefox 不支持）全部静默降级，不影响计时
- 详情页 iframe 补 `allow="screen-wake-lock"`，同源继承之外再加一层显式声明
- 浏览器支持：Chrome/Edge 84+、Safari 16.4+；Firefox 不支持。需 HTTPS（线上满足）

### 利率加减按钮（同日）
- LPR / 基点 / 公积金利率三个输入都带 `−` / `+`，步长统一 5 个基点：
  LPR 与公积金利率 ±0.05%，基点 ±5（200 万 30 年月供每档约 60 元，可感知又不粗）
- 形态：中间数值 + 两侧按钮合成一个胶囊（`.stepper`，高 32px、圆角 10px、内部细分隔线），
  不是三个漂浮元素；`:has(:focus-visible)` 让整颗胶囊跟着聚焦发光
- 交互：单击一步；按住 420ms 后每 90ms 连走一步（`pointerdown` 立即响应，
  `pointerup/pointerleave/pointercancel` 停止）；`click` 只在 `detail === 0`（键盘）时补触发，
  避免指针点击被算两次
- 边界处理：`paintStepButtons()` 在 update 里刷新 disabled，到 0 / -300 / 24 等边界自动置灰
- 手机适配：`@media (max-width: 420px)` 下 rate-grid 改单列、按钮放大到 36px
- 数值区用 `display: block; text-align: center` + `.num{width:3em;text-align:right}` 让
  「数字 + 单位」成组居中（纯 flex 居中会把 % 推到右边缘）

### 步进控件收紧（同日二改）
- 最初 `.stepper{flex:1}` 会把数值区拉满，减号离数字太远
- 改为 `inline-flex` + `width:auto` + `margin-left:auto`：胶囊宽度只够「按钮 + 数字 + 按钮」（约 105px）
- 单位（%/BP）从胶囊里挪到 label 上（`.label-unit`，11px 灰字），
  这样胶囊里只剩数字，`text-align:center` 即为真正的视觉居中
- 桌面按钮 28px、数值区 `width:2.7em`；手机仍 36px 触屏尺寸
