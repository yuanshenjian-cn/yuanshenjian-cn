## 番茄钟：计时期间屏幕常亮

- 用 Screen Wake Lock API（`navigator.wakeLock.request('screen')`）
- 接入点：`commit()` 里 `wakeLock.sync(status === 'running')`，覆盖开始/暂停/重置/切换轮次全部路径

- 详情页 iframe 补 `allow="screen-wake-lock"`，同源继承之外再加一层显式声明
- 浏览器支持：Chrome/Edge 84+、Safari 16.4+；Firefox 不支持。需 HTTPS（线上满足）

### 身体指标计算器（slug: body）
- 入口 `site/public/tools/body/view.html`，主题青 `#0e8496` / 暗色 `#43c6db`
- 深度调研口径（可复用到其他健康类工具）：
  - 证据第一梯队：VO₂max（AHA 2016 列为 clinical vital sign）、握力（每降 5kg 全因死亡 +16%）、
    腰围/腰高比（84 万人研究：仅 BMI 超标而腰围正常者死亡风险不升高）、血压、单腿站立 10 秒
  - 易误读：BMI 不分肌肉脂肪；家用 BIA 体脂 ±5pp 只看趋势；手表压力值/HRV 是厂商黑箱
- 公式与常模：
  - HRmax 用 Tanaka `208 − 0.7×age`（SEE ≈10bpm），不用 220−age（高估年轻人、低估老年人）
  - 五区：无静息心率走 %HRmax（50/60/70/80/90）；填了走 Karvonen `HRrest + %×(HRmax−HRrest)`
  - VO₂max 估算 Uth `15.3 × HRmax ÷ HRrest`，分级用 Cooper Institute 常模（6 档合并为 4 档）
  - 体脂留空用 Deurenberg `1.2×BMI + 0.23×age − 10.8×sex − 5.4`
  - BMR 用 Mifflin-St Jeor；FFMI = LBM/h²
  - BMI 分级用中国标准 18.5 / 24 / 28；腰围上限 男 90 / 女 85；握力阈值 AWGS 男 28 / 女 18
- 交互坑：
  - 可选数值用 `null` 表示「未填」，input 留空 + placeholder；步进时以 `base` 起步再 clamp
  - `restore()` 必须逐字段校验并 clamp，localStorage 脏数据会把结果算成 NaN
  - 刻度条 pin 用线性映射（BMI 14–36、WHtR 0.35–0.75），段宽按同一映射的百分比写死，视觉才自洽
  - `rm -rf .next dist` 超过 50 文件会被 safe-delete 拦，需 `dangerouslyDisableSandbox` 单独执行

### 身体指标计算器：空状态按钮改弹层
- 「去填腰围 / 去填心率」原用 `scrollIntoView` + `focus()`，在 iframe 内定位不可靠，用户感知为「点了没反应」
- 改为原生 `<dialog>` + `showModal()` + `::backdrop`：弹层内 stepper、实时预览（腰高比 / 心率储备）、保存 / 取消
- 交互细节：Enter 保存（仅 input 内）、Esc 取消、点遮罩关闭、`close` 事件统一恢复滚动锁
- 滚动锁：open 时 `html/body.style.overflow = hidden`，否则 showModal 期间背景仍会被滚轮带走
- 弹层 primary 按钮用 `color: var(--surface)` 而非 `#fff`，浅色 / 暗色两套主题下对比度都成立
- **dist 是 dev/build 共用目录**（`distDir: "dist"` + `output: "export"`）：跑 dev 会把 export 产物覆盖成开发结构，
  验证产物必须先停 dev 再 build
- 构建必须 `NODE_OPTIONS="" npm run build`，否则被注入的 sandbox fs shim 拦成 `ENOENT`
- 工具改名「健康指示器」（slug 仍为 `body`，副本改名 `~/Personal/实用小工具/health-indicator.html`）
- 心率五区配色：Z1 蓝 `#6b93bd` / Z2 青绿 `#17a07f` / Z3 金 `#d1a01a` / Z4 橙 `#d9772e` / Z5 红 `#cd584d`，
  色条用 `--zc`、bpm 数字用 `--zc-ink`（加深版）——色条要鲜明、文字要够对比度，两者不能共用同一个值
- 只有 Z4/Z5 保留 `is-anaerobic` 淡色底，色条五条各不相同即可区分等级
